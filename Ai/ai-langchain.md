## 介绍

`LangChain` 是一个开源的大模型智能体开发框架, 支持主流大模型  

## LangChain

- Model 大模型对象
- Messages 上下文内容
- Tools 定义智能体可用的工具
- Agent 将以上内容组合成智能体
- Memory 智能体记忆
